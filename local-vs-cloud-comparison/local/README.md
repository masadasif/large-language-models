# Local LLMs Experiment

This directory contains a series of experiments comparing the capabilities of different Large Language Models (Local vs Cloud).

## Projects

### Password Strength Checker
A modern, responsive password strength checker built with vanilla web technologies.

- **Technologies**: HTML5, CSS3, JavaScript (ES6+)
- **Features**:
    - Live strength detection as you type.
    - Visual feedback via an animated progress bar.
    - Validation hints for:
        - Length (min 8 characters)
        - Uppercase letters
        - Lowercase letters
        - Numbers
        - Special characters
    - Password visibility toggle.
    - Responsive card layout.

## Objectives
- Compare code quality across different models.
- Evaluate ability to follow specific architectural constraints (no frameworks).
- Test UI/UX design capabilities.

# large-language-models

A personal repository for experimenting with different Large Language Models.

## About

This repo is a workspace for hands-on exploration of LLMs — comparing models, evaluating capabilities, and prototyping ideas. Over time, it will grow to host a collection of independent projects and experiments, each in its own folder.

## Structure

Each experiment or project lives in its own top-level folder, with subfolders organizing the components of that experiment.

```
large-language-models/
└── local-vs-cloud-comparison/   # First experiment: compare a local LLM against cloud-hosted models
    ├── local/                   # Local LLM setup, prompts, and results
    └── cloud/                   # Cloud LLM setup, prompts, and results
```

## Current experiment

**local-vs-cloud-comparison** — Comparing the behavior, quality, and performance of a locally-run LLM against cloud-hosted equivalents.

## Planned

More experiments and projects will be added as separate top-level folders as the work progresses.
